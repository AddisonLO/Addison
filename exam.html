Web Development Notes

HTML

  • <!DOCTYPE html>: Declares HTML5 document type
  • <ul><li> / <ol><li>: Lists
  • <a href=""></a>: Hyperlink
  • Semantic tags: <header>, <nav>, <article>, <section>, <aside>, <footer>
  • <script> / <noscript>: JavaScript inclusion / fallback

CSS

  • Import methods: inline, internal, external
  • Structure: selector { property: value; }
  • Selectors: element, class (e.g. .title)
  • Properties: margin, padding, color, font-size, font-weight, font-style, font-family, text-decoration, text-align, line-height
  • background: color, image, repeat, size, position, attachment
  • List styles: none, disc, square, circle
  • display: block, inline, inline-block
  • float: left, right
  • overflow: visible, hidden, scroll, x/y

JavaScript

Basics

  • document.write()
  • Loop example: for (let i = 0; i < 10; i++) { document.write(i); }
  • String building with +=
  • Operators: +, -, *, /, +=, -=, *=, %=, comparisons
  • String concatenation: template literals ${} or +
  • Loops: for, while, do...while
  • Array methods: push(append), unshift(prepend), pop(remove the last), shift(remove the first),length(length of the array)
  • Structure: function functionName() { } e.g: 
     
              function showGreeting() {
                  console.log("Hello, World!");
              }

DOM Manipulation

  • DOM Tree: document → html → head → title, meta, link, script; body → header, section, article, nav, aside, footer, h1–h6, p, ul/ol/li, a, img, div
  • Create elements: createElement() e.g: 
    const newDiv = document.createElement("div");
  • Add context: 
                
    
            const newDiv = document.createElement("div");
            newDiv.textContent = "Hello, World!";
            document.getElementById("root").appendChild(newDiv);
            document.body.appendChild(newDiv);
